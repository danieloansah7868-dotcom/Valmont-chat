Turn VChat into a real app

A PWA is still Chrome or Safari with an icon. A real app is an APK, IPA, or desktop window you install like WhatsApp.

Cloud is navy

Internet messages on VChat Cloud. Groups, secret chats, files, and every signed-in device.

SMS is orange

One-to-one texts leave through Twilio. That is not Apple Messages, and it is not the SIM SMS app on this phone.

What a PWA cannot do

  • It lives inside a browser. Android can kill it in the background.
  • It cannot be the default SMS app or write into the system Messages database.
  • It cannot ship on Google Play or the App Store as a native package.
  • Camera, mic, and file access go through browser permission prompts.

Android APK (the usual “real app”)

  1. Install Android Studio on your computer.
  2. Open the folder native/android from this repository.
  3. Edit app/src/main/res/values/strings.xml and set vchat_server_url to your live VChat HTTPS address (the same URL people use in a browser).
  4. Build → Build Bundle(s) / APK(s) → Build APK(s).
  5. Copy the APK to a phone and install it. On first launch it opens VChat full-screen, with no browser bar.
cd native/android
# optional command-line build once the Android SDK is installed
./gradlew assembleDebug

Play Store: you need a Google Play developer account, a signed release build, a privacy policy URL, and store listing screenshots. This sandbox cannot publish for you.

Desktop (Windows, macOS, Linux)

cd native/desktop
npm install
VCHAT_SERVER_URL=https://your-vchat-host npm start

To make an installer: npm run dist after you set the server URL.

iPhone / iPad

Apple will not let a Linux sandbox ship an App Store build. On a Mac, create an iOS App project in Xcode, drop in the files under native/ios, set the server URL, and archive with a paid Apple Developer account.

Honest limits

  • The native shell is a full-screen WebView talking to your existing VChat server. That is how many hybrid messengers ship a first store build.
  • It does not become iMessage, WhatsApp’s native stack, or your carrier’s SMS app.
  • Secret-chat keys still stay on the device. They are not in the cloud backup.
  • Push notifications that wake a killed app need Firebase / APNs later. This first shell uses the same in-app alerts as the website.
